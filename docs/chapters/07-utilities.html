Searching, cross-referencing identifiers, filtering, exporting results, and generating plots

9.1 Overview

This chapter covers the practical mechanics of navigating the KG: searching by identifier, cross-referencing databases, filtering results, exporting data, and generating visualisations.

Threshold Recommended value Edge property
DEG adjusted p-value < 0.05 adj_pvalue
DEG absolute log₂FC > 1 abs_log2fc
Spearman correlation |r| > 0.5 correlation_factor
MOFA weight (top features) > 80th percentile mofa_weight
WGCNA module membership kME > 0.5 network_membership
TF enrichment padj < 0.05 padj
Pathway enrichment padj < 0.05 padj

9.6 Plotting Routines

The KG can generate a variety of visualisations directly from query results. Ask Co-Scientist to produce plots alongside tabular output.

What kinds of plots can you generate for KG query results?

Plots are generated directly by the Co-Scientist from KG data. The following types are available, each backed by specific KG edge properties:

Plot type KG data source When to use
KG subgraph / network view Any edge type (e.g., upregulated, positive, gene_part_of, metabolic chains gene→kegg_ortholog→kegg_enzyme→kegg_reaction→metabolite) Visualise relationships around a specific gene, protein, or metabolite; trace metabolic paths
Volcano / scatter plot upregulated / downregulated edges: x = abs_log2fc, y = -log10(pvalue), colour by edge type DEG/DAA — identify significant differentially expressed features per cohort
Expression heatmap gene_expressed_in.abs_log2_tpm, protein_abundant_in.abs_log2_abundance, metabolite_abundant_in.abs_log2_abundance; faceted by harvest_day, clone_id, molecule Compare expression profiles across samples, clones, or molecules
Enrichment bar / lollipop go_term_enriched_in and kegg_pathway_enriched_in: y = -log10(padj) Top enriched GO terms or KEGG pathways per cohort, network, or factor
Enrichment dot / bubble plot Same enrichment edges: y = term, x = enrichment_score, size = overlap, colour = -log10(padj) Compare enrichment across multiple terms simultaneously
WGCNA module–phenotype bars gene/protein/metabolite_network_correlated_with_phenotype: pearson_correlation with fdr, coloured by direction Which modules are pro- or anti-productivity
MOFA factor correlation bars factor_correlated_with_phenotype.correlation, coloured by direction Which MOFA factors correlate with qP, titre, IVCD
MOFA loadings plot mofa_weight from gene/protein/metabolite_contributes_to_factor Top features driving each factor, per omics layer
Pathway treemap / sunburst pathway.top_level_mapping_broad and top_level_mapping_subcategory Hierarchical breakdown of enriched pathways by KEGG BRITE category
Bioprocess time-series measured_in.bms_bioprocess_parameter_value over Sample.harvest_day, faceted by molecule or qp_group qP, titre, lactate, glucose trends across culture days
Cohort summary stacked bar Count of upregulated/downregulated entities per cohort; or top enriched pathway by padj Overview of DE landscape across multiple cohorts

9.8 Tips for Effective Queries

  • Be specific about entity type — say “gene”, “protein”, or “metabolite” explicitly
  • Name the cohort — include molecule, clone, and study when relevant
  • State directionality — “upregulated”, “positive MOFA weight”, “negatively correlated with qP”
  • Include exact thresholds — numbers rather than “strong” or “significant”
  • Build progressively — start broad, then add constraints to narrow results
  • Reference modules and factors by name — network_2_gene, Factor1, not “the pro-productivity module”
Tip

If results feel off-topic, start a New Session (pencil icon, top right) to clear accumulated context, then rephrase your query with more specificity.
